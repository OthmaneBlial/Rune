# Support

Rune is an alpha source preview. The strongest supported surface today is the
bounded Rust workspace and local `rune-cli`; the SwiftUI/UIKit layer is
source-only until a real Apple toolchain is available.

## Where to ask

- Use the [bug report template](https://github.com/OthmaneBlial/Rune/issues/new?template=bug_report.yml)
  for a reproducible defect.
- Use the [feature request template](https://github.com/OthmaneBlial/Rune/issues/new?template=feature_request.yml)
  for a proposed workflow or capability.
- Use the [compatibility observation template](https://github.com/OthmaneBlial/Rune/issues/new?template=compatibility-observation.yml)
  for captured a-Shell or platform behavior.
- Read the [documentation](https://othmaneblial.github.io/Rune/docs.html),
  [development guide](docs/development.md), and [roadmap](ROADMAP.md) before
  opening a question already covered there.

## Security

Do not publish credentials, private paths, tokens, host inventories, exploit
details, or real private captures. Follow [SECURITY.md](SECURITY.md) and use
GitHub's private vulnerability reporting when available.

When reporting a problem, include the affected commit or release, the exact
safe reproduction, expected versus observed behavior, and the OS,
architecture, and toolchain used. Keep claims scoped to the evidence you can
share.
